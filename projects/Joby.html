Contributions

BOM Smartsheet Comparator

Developed an internal cross-functional tool that reconciled the source-of-truth aircraft data against multiple engineering team data. The tool identified information that were missing from data, incorrectly formatted, overdue, or not aligned with up to date data.

  • Built Python, SQL, and PySpark data-processing tools in Databricks to standardize data from various sources.
  • Developed a pipeline that extracted information from inconsistent data.
  • Connected data with databricks to keep the engineering view up to date.
  • Created automated checks that identified errors, mistmatches, and reviewed data.
  • Replaced multiple manually cross-referenced data process with an automated workflow that could be run with a single click.
  • Deployed a accessible and easy to use frontend interface.
  • Impact: Reduced manual data reconciliation while giving program managers a centralized way to identify missing work and discrepancies.

Sensor Calibration Tracker

Digitized and automated the Flight Test Instrumentation team's sensor calibration records to improve accessibility, traceability, and compliance during aircraft flight testing.

  • Converted physical calibration records stored in the FTI team's inventory into a centralized digital database.
  • Developed a dashboard to track sensor model numbers, locations, purchasers, calibration dates, and aircraft assignments.
  • Developed a digital dashboard to organize sensor records, improve traceability, and provide automated reminders for upcoming recalibration
  • Allowed engineers to add, remove, and update sensors as instrumentation configurations changed during aircraft development and testing.
  • Improved traceability of sensor calibration records supporting flight test activities, FAA compliance, and aircraft Type Certification.
  • Impact: Replaced a physical-only recordkeeping process with an accessible and maintainable digital tracking system for flight-test instrumentation.
